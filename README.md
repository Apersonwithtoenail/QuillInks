# Quillinks

A modern terminal text editor. Mouse support, syntax highlighting, and shortcuts that do not require a 40-year-old manual.

## Install

    python3 -m venv .venv
    source .venv/bin/activate
    pip install textual

## Run

    python quillinks.py filename.txt

## Shortcuts

| Key | Action |
|-----|--------|
| Ctrl+S | Save |
| Ctrl+Q | Quit |
| Ctrl+N | New file |
| Mouse | Click to position cursor |
